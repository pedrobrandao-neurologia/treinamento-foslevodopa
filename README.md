# treinamento-foslevodopa

Vídeos de treinamento, em português, para pacientes e cuidadores que vão iniciar a infusão subcutânea de foslevodopa/foscarbidopa.

Página dos pacientes: https://pedrobrandao-neurologia.github.io/treinamento-foslevodopa/

Para abrir a página já em um vídeo específico, acrescente `#video-NN` ao endereço (por exemplo, `#video-05`).

## Conteúdo

- `index.html`: página com os 16 vídeos (cerca de 38 minutos no total)
- `videos/`: os vídeos, com narração e legendas em português
- `capas/`: imagem de capa de cada vídeo
- `legendas/`: legendas em arquivo `.srt`
